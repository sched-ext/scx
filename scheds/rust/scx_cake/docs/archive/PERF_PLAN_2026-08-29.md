## Slide 7 — Lever 5: §G12 KEYSTONE re-base (architectural)

- **Claim:** bystander tasks pay for the desktop crowd's tightened patience
  windows; the same-CPU handoff tail pays (mode-switch root cause, 8/19).
  This is why g43 wins menus but loses loaded tails — one global clock.
- **Design:** re-base `FRAME_*_SHIFT` windows onto the occupant's OWN period
  (dimensionless ratios stay; `HOME_PREEMPT_RAN_CREDIT_SHIFT` is kept as-is).
  Eliminates the last tuned-magnitude constants (registry table, STATE.md
  KEYSTONE section).
- **Why now:** it dissolves the g43 menu-vs-loaded trade instead of tuning
  around it; it is the last architectural constant family standing.
- **Cost:** the largest build on this board; needs dose + rotation + guards.
  Maintainer call on ordering vs levers 1–4.

## Slide 10 — Lever 9: the kernel ask (P1 fused place)

- **Frame:** sched_ext pays a 15–20 ns trampoline per callback (structural);
  BPF floor 65–70 ns; today 80 ns @ ~150k/s ≈ 12k µs/s. The 8k µs/s line is
  2–3k µs/s out of reach in pure BPF. Wake path = 3–4 kernel crossings.
- **P1** collapses them into one fused place kfunc (accept + atomic claim +
  LOCAL_ON + conditional kick): ~20–35 ns/wake claimed, high certainty —
  the only patch with headroom worth its cost.
- **Pre-work (census first, §G57):** the mailbox-miss path falls to the full
  ladder on ~25% of wakes; if hit-rate work shrinks the miss share first,
  P1's payoff concentrates where wakes remain.
- **P2** DSQ emptiness push (event-complete, deletes rq-lock queries) rides
  any rebuild cycle independently. P3 lazy kick needs a kick-target census
  first; P4/P5 priced low — do not build.
- **Also kernel-lane:** §G51 one-line attach fix BEFORE the BIOS C-state
  change (else a session is lost testing the wrong hypothesis); the
  direct-write deprecation removal deadline (§R.17 +28–36% stopping) needs an
  exemption-or-accept decision this cycle; PI wakeups land upstream in 7.3
  (§G56) — do not duplicate.
